TagIT: Giving the Physical World a Digital Identity

A Step-by-Step Build Cookbook — RC522, ESP32 & OLED

How This Cookbook Works

We are not going to jump straight to "build an RFID login system." That's how you end up with a pile of components that don't talk to each other and no idea which one is broken.

Instead, we build one capability at a time, test it, and only then bolt on the next one — and every step here maps to a real, working .ino file already sitting in this project folder.

We start with three quick Warm-Ups — LED, buzzer, OLED — each on its own, then a short challenge that drives all three at once. Only then do we bring in the RFID reader and work through the phases below:

PhaseYou will be able to...New hardware addedFile
1Read a physical tag's unique identity over SPIRC522 reader + tagsphase1_rfid_read
2Make the board "speak" through text and lightOLED display + onboard LEDphase2_read_oled
3Turn identity into an Access Granted / Denied decisionBuzzerphase3_auth_oled
4Turn a scan into a Clock-In / Clock-Out decision, with duration(logic only — multi-card registry)phase4_clockinout_oled
5Send that decision to a live server over Wi-FiWi-Fi + HTTP serverphase5_wifi_server_oled

By Phase 5 you will have exactly the system described in the brief: scanning a tag retrieves identity, records the interaction, triggers a local action (LED/buzzer/OLED), and pushes the event to a server that feeds a live clock-in/out dashboard.

Every phase ends with a Checkpoint A specific thing you should see happen. Do not move to the next phase until your checkpoint passes.

Warm-Ups — Get Each Part Working Alone

Before touching the RFID reader, prove that the three "output" parts of the build work on their own: the LED, the buzzer, and the OLED. Each one is tiny, takes a minute to flash, and gives you a known-good building block. If something breaks later, you already know these three work.

Do these in order LED → Buzzer → OLED → then the Integration Challenge that drives all three at once. Only after that do we start reading tags.

1. LED Blink

warmup1_led_blink/warmup1_led_blink.ino

Goal

Turn the ESP32's onboard LED on for one second, off for one second, forever. The classic "hello world" of hardware — it confirms your board, cable, and upload toolchain all work.

A Little Theory

  • A GPIO ("General Purpose Input/Output") pin is a single wire the chip can drive HIGH (~3.3 V) or LOW (0 V).
  • pinMode(pin, OUTPUT) tells the chip we want to drive that pin, not read it.
  • digitalWrite(pin, HIGH/LOW) sets the voltage. The onboard LED on most 30-pin ESP32 boards sits on GPIO 2, so no wiring is needed.
  • delay(ms) pauses the program. Without it the LED would toggle millions of times a second and just look dimly on.

Full Code

cpp#define LED_PIN 2

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  // LED ON
  delay(1000);                  // Wait 1 second

  digitalWrite(LED_PIN, LOW);   // LED OFF
  delay(1000);                  // Wait 1 second
}
✅ Checkpoint

The small onboard LED blinks a steady 1 s on / 1 s off.

Common Errors
  • Nothing blinks: wrong port selected, charge-only USB cable, or your board's onboard LED is on a different GPIO — check the silkscreen.
  • Upload fails: hold the BOOT button while it says "Connecting…".

2. Buzzer Test

warmup2_buzzer/warmup2_buzzer.ino

Goal

Make the buzzer beep for half a second, then go silent for half a second, on repeat.

A Little Theory

  • A buzzer makes sound only when its signal wire oscillates — a flat HIGH just gives a faint "tick". You need a square wave at an audible frequency (a few kHz).
  • On the ESP32 the ledc peripheral generates that wave in hardware: ledcAttach(pin, freq, resolution) sets it up, ledcWriteTone(pin, freq) starts a tone, and ledcWriteTone(pin, 0) stops it.
  • Wiring: buzzer I/O → GPIO 4, VCC → 3.3V, GND → GND.

Full Code

cpp#define BUZZER_PIN 4

void setup() {
  pinMode(BUZZER_PIN, OUTPUT);

  // Generate a 5 kHz tone
  ledcAttach(BUZZER_PIN, 5000, 8);
}

void loop() {
  ledcWriteTone(BUZZER_PIN, 5000);
  delay(500);

  ledcWriteTone(BUZZER_PIN, 0);
  delay(500);
}
Note ledcAttach() is the ESP32 Arduino core 3.x API. On older 2.x cores use ledcSetup() + ledcAttachPin(). The later RFID phases use the simpler tone()/noTone() — either approach makes the same beep.
✅ Checkpoint

You hear a clean, steady beep-silence-beep at roughly one beep per second.

Common Errors
  • Only a faint click: you drove the pin HIGH/LOW instead of using a tone function.
  • No sound at all: passive buzzer wired where an active one is expected, or I/O pin not on GPIO 4.

3. OLED Test

warmup3_oled/warmup3_oled.ino

Goal

Print two lines of text to the 128×64 OLED and leave them on screen.

A Little Theory

  • This OLED talks over I²C: two shared wires, SDA (data) and SCL (clock). On the ESP32 we use SDA → GPIO 21, SCL → GPIO 22.
  • Every I²C device has an address; these panels are almost always 0x3C (sometimes 0x3D).
  • The Adafruit library keeps a pixel buffer in RAM. You draw into it (clearDisplay, setCursor, println) and nothing shows until display.display() pushes the buffer to the panel.

Full Code

cpp#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64

#define OLED_SDA 21
#define OLED_SCL 22

#define OLED_RESET -1
#define OLED_ADDRESS 0x3C

Adafruit_SSD1306 display(
  SCREEN_WIDTH,
  SCREEN_HEIGHT,
  &Wire,
  OLED_RESET
);

void setup() {

  // Start I2C
  Wire.begin(OLED_SDA, OLED_SCL);

  // Initialize OLED
  if (!display.begin(SSD1306_SWITCHCAPVCC, OLED_ADDRESS)) {
    Serial.begin(115200);
    Serial.println("OLED NOT FOUND!");
    while (true);
  }

  Serial.begin(115200);
  Serial.println("OLED FOUND!");

  // Clear display
  display.clearDisplay();

  // Text settings
  display.setTextSize(2);
  display.setTextColor(SSD1306_WHITE);

  display.setCursor(10, 10);
  display.println("YOO ");

  display.setTextSize(2);
  display.setCursor(10, 30);
  display.println("NIATIAN!");

  display.display();
}

void loop() {
  // Nothing needed
}
✅ Checkpoint

The OLED shows two lines of large text and holds them.

Common Errors
  • Screen stays black: try address 0x3D, and double-check SDA/SCL aren't swapped.
  • Serial prints "OLED NOT FOUND!": power the panel from 3.3V and confirm GND is shared with the ESP32.
  • Drew text but nothing appears: you forgot display.display().

4. Integration Challenge — All Three Together

Challenge
warmup4_integration/warmup4_integration.ino

Your Task

Combine the three warm-ups into one sketch. In a loop, alternate between an "ON" state and an "OFF" state, once per second:

  • ON state: LED HIGH, buzzer sounding, OLED shows BUZZER ON.
  • OFF state: LED LOW, buzzer silent, OLED shows BUZZER OFF.

The point: get comfortable initialising all three peripherals in one setup() and driving them from one loop() without them interfering. This is the exact pattern every RFID phase after this uses.

Hints

  • Do all three begin/pinMode/ledcAttach calls in setup().
  • Redraw the OLED each state change and call display.display().
  • One delay(1000) after each state is enough.

Reference Solution

cpp#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define BUZZER_PIN 4
#define LED_PIN 2

#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64

#define OLED_SDA 21
#define OLED_SCL 22
#define OLED_RESET -1
#define OLED_ADDRESS 0x3C

Adafruit_SSD1306 display(
  SCREEN_WIDTH,
  SCREEN_HEIGHT,
  &Wire,
  OLED_RESET
);

void setup() {

  pinMode(LED_PIN, OUTPUT);

  Wire.begin(OLED_SDA, OLED_SCL);

  if (!display.begin(SSD1306_SWITCHCAPVCC, OLED_ADDRESS)) {
    while (true);
  }

  // Set buzzer frequency
  ledcAttach(BUZZER_PIN, 5000, 8);
}

void loop() {

  // =========================
  // BUZZER ON
  // =========================

  digitalWrite(LED_PIN, HIGH);
  ledcWriteTone(BUZZER_PIN, 5000);

  display.clearDisplay();

  display.setTextSize(2);
  display.setTextColor(SSD1306_WHITE);

  display.setCursor(5, 20);
  display.println("BUZZER ON");

  display.display();

  delay(1000);


  // =========================
  // BUZZER OFF
  // =========================

  digitalWrite(LED_PIN, LOW);
  ledcWriteTone(BUZZER_PIN, 0);

  display.clearDisplay();

  display.setTextSize(2);
  display.setTextColor(SSD1306_WHITE);

  display.setCursor(5, 20);
  display.println("BUZZER OFF");

  display.display();

  delay(1000);
}
✅ Checkpoint

Every second: LED + beep + BUZZER ON on the screen, then LED off + silence + BUZZER OFF. All three parts change together, cleanly.

You now have every output the project needs. From here on we add the one input — the RFID reader — and let a tag decide when these outputs fire.

Phase 1 — RC522 + ESP32 Interfacing

Phase 1
phase1_rfid_read/phase1_rfid_read.ino

Goal

Give a physical tag a readable digital identity: detect an RFID card/tag with the RC522 reader and print its UID (Unique ID) to the Serial Monitor. This is the core sensor of the whole project — everything else is built on top of this UID.

Library Required

  • MFRC522 by GithubCommunity / Miguel Balboa (Arduino Library Manager)

Wiring (ESP32 30-pin board <-> RC522, using VSPI)

RC522 PinESP32 Pin
SDA (SS)GPIO 5
SCKGPIO 18
MOSIGPIO 23
MISOGPIO 19
IRQNot connected
GNDGND
RSTGPIO 27
3.3V3.3V (RC522 is not 5V tolerant — do not use VIN/5V)

Full Code

cpp#include <SPI.h>
#include <MFRC522.h>

#define SS_PIN   5
#define RST_PIN  27

MFRC522 rfid(SS_PIN, RST_PIN);

void setup() {
  Serial.begin(115200);
  while (!Serial);          // wait for Serial Monitor to open

  SPI.begin();               // start SPI bus (default VSPI pins on ESP32)
  rfid.PCD_Init();           // initialize the RC522 reader

  Serial.println("Phase 1: RC522 + ESP32 ready.");
  Serial.println("Scan a card...");
}

void loop() {
  // Step 1: Is a new card present?
  if (!rfid.PICC_IsNewCardPresent()) {
    return;
  }

  // Step 2: Can we read its serial (UID)?
  if (!rfid.PICC_ReadCardSerial()) {
    return;
  }

  // Step 3: Print the UID in HEX, byte by byte
  Serial.print("Card UID: ");
  for (byte i = 0; i < rfid.uid.size; i++) {
    Serial.print(rfid.uid.uidByte[i] < 0x10 ? " 0" : " ");
    Serial.print(rfid.uid.uidByte[i], HEX);
  }
  Serial.println();

  // Step 4: Print card type (optional, useful for debugging)
  MFRC522::PICC_Type piccType = rfid.PICC_GetType(rfid.uid.sak);
  Serial.print("PICC type: ");
  Serial.println(rfid.PICC_GetTypeName(piccType));

  // Step 5: Halt PICC and stop crypto so the next scan works cleanly
  rfid.PICC_HaltA();
  rfid.PCD_StopCrypto1();
}

Code Walkthrough

  • MFRC522 rfid(SS_PIN, RST_PIN): creates the reader object bound to the ESP32 pins used for Slave Select and Reset.
  • SPI.begin(): starts the SPI bus. On ESP32 the default VSPI pins are SCK=18, MISO=19, MOSI=23, SS=5 — matches our wiring exactly, so no pin remap is needed.
  • PICC_IsNewCardPresent(): polls the reader; returns true only the instant a new tag enters the field.
  • PICC_ReadCardSerial(): actually reads the UID bytes from the tag — this UID is the tag's digital identity for every later phase.
  • rfid.uid.uidByte[i]: the UID is stored as an array of bytes (4 or 7 bytes depending on card type — Mifare Classic 1K cards are usually 4).
  • PICC_HaltA() + PCD_StopCrypto1(): cleanly ends the session with the tag so scanning is reliable and repeatable.

Open Tools → Serial Monitor at 115200 baud, tap each of your tags, and write down the UID printed for each one (e.g. 93 A7 4C 21) — you'll hardcode these in Phase 3.

✅ Checkpoint

Hold Card 1 near the reader (1–3 cm) → a UID prints. Remove and hold Card 2 → a different, repeatable UID prints.

Common Errors
  • Nothing prints ever: check 3.3V (not 5V) power, and that SDA→5, RST→27 aren't swapped.
  • Random/garbage UID or it changes every time: RST pin not connected, or a loose SPI wire (MISO/MOSI swapped).
  • Board resets/browns out when card is scanned: RC522 sometimes needs a dedicated 3.3V pin — do not share it with other high-draw modules.
  • Library not found: install "MFRC522" by GithubCommunity from the Arduino Library Manager.

Challenge — Make a Scan Trigger LED + Buzzer + OLED

Challenge
challenge1_scan_feedback/challenge1_scan_feedback.ino

Your Task

You can now read a UID (Phase 1) and you have the three outputs working (Warm-Ups). Wire them together: every time a tag is read, the board should react —

  • the LED blinks,
  • the buzzer beeps,
  • the OLED shows Card Detected and the UID.

Then it returns to an idle "Tap a card…" screen, ready for the next scan. No access logic yet — any tag triggers the same reaction. This is the bridge between "reading a number" and "the system does something you can see and hear."

Hints

  • Start from the Phase 1 present/read/halt sequence.
  • Turn the raw UID bytes into one uppercase hex string so it fits cleanly on the OLED.
  • Drive the LED and buzzer from a single helper so they always fire together.
  • A short delay() after showing the UID keeps it readable before the idle screen returns.

Reference Solution

cpp#include <SPI.h>
#include <MFRC522.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SS_PIN     5
#define RST_PIN    27
#define BUZZER_PIN 4
#define LED_PIN    2      // ESP32 onboard LED on most 30-pin boards

#define SCREEN_WIDTH   128
#define SCREEN_HEIGHT  64
#define SCREEN_ADDRESS 0x3C   // try 0x3D if the screen stays blank

MFRC522 rfid(SS_PIN, RST_PIN);
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

void setup() {
  Serial.begin(115200);
  while (!Serial);

  SPI.begin();
  rfid.PCD_Init();

  pinMode(LED_PIN, OUTPUT);
  digitalWrite(LED_PIN, LOW);

  Wire.begin(21, 22);  // SDA, SCL
  if (!display.begin(SSD1306_SWITCHCAPVCC, SCREEN_ADDRESS)) {
    Serial.println("OLED not found - check wiring/address.");
  }

  showMessage("Scan Feedback", "Tap a card...");
  Serial.println("Challenge: RFID -> LED + Buzzer + OLED ready.");
}

void loop() {
  if (!rfid.PICC_IsNewCardPresent()) return;
  if (!rfid.PICC_ReadCardSerial())   return;

  String uid = getUIDString();
  Serial.print("Card UID: ");
  Serial.println(uid);

  // ---- the three warm-ups, now fired by a real tag read ----
  showMessage("Card Detected", uid);   // OLED  (warm-up 3)
  feedback(2);                         // LED + buzzer together (warm-ups 1 + 2)

  rfid.PICC_HaltA();
  rfid.PCD_StopCrypto1();

  delay(1200);
  showMessage("Scan Feedback", "Tap a card...");
}

// Raw UID bytes -> uppercase hex string, e.g. "93A74C21"
String getUIDString() {
  String result = "";
  for (byte i = 0; i < rfid.uid.size; i++) {
    if (rfid.uid.uidByte[i] < 0x10) result += "0";
    result += String(rfid.uid.uidByte[i], HEX);
  }
  result.toUpperCase();
  return result;
}

void showMessage(String line1, String line2) {
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0, 10);
  display.println(line1);
  display.setCursor(0, 30);
  display.println(line2);
  display.display();
}

// Plays `count` beeps and blinks the LED `count` times, together, in sync.
void feedback(int count) {
  for (int i = 0; i < count; i++) {
    tone(BUZZER_PIN, 1000);
    digitalWrite(LED_PIN, HIGH);
    delay(180);
    noTone(BUZZER_PIN);
    digitalWrite(LED_PIN, LOW);
    delay(150);
  }
}
✅ Checkpoint

Tap any tag → LED blinks, buzzer beeps, OLED shows the UID, then it falls back to "Tap a card…". Tapping a different tag shows a different UID with the same reaction.

Where this goes next Right now every tag gets the same beep. The following phases add meaning to the UID: first a name and an authorised / not-authorised decision, then login / logout state, then pushing each event to a Wi-Fi dashboard.

Phase 2
phase2_read_oled/phase2_read_oled.ino

Goal

Give the system a voice. Same detection as Phase 1, now displayed as text on an OLED screen, plus blinking the ESP32's built-in LED (GPIO 2 on most 30-pin boards) as a visible "card detected" signal — no extra wiring needed for the LED, it's already on the board.

cpp#include <SPI.h>

// Blinks the onboard LED `times` times, `onOffMs` on and off each time.
void blinkLED(int times, int onOffMs) {
  for (int i = 0; i < times; i++) {
    digitalWrite(LED_PIN, HIGH);
    delay(onOffMs);
    digitalWrite(LED_PIN, LOW);
    delay(onOffMs);
  }
}

Code Walkthrough

  • getUIDString(): turns the raw UID bytes from Phase 1 into a clean, comparable string like "93A74C21" — this exact string format is what Phase 3 will compare against known cards.
  • LED_PIN 2: the onboard LED on most ESP32 30-pin dev boards is wired to GPIO 2 — check yours has a small LED right next to a pin labeled "2"/"D2" on the silkscreen to confirm before assuming.
  • blinkLED(times, onOffMs): a small reusable helper, same pattern as showMessage() — blinks the LED a set number of times with an on/off delay each. Called once per card detection.
✅ Checkpoint

Tap a card — the onboard LED blinks 4 times quickly while the OLED shows "Card Detected" + the UID.

Common Errors
  • LED never blinks: some ESP32 board variants use a different GPIO for the onboard LED — check your board's silkscreen/datasheet if GPIO 2 doesn't do anything.
  • LED stays on solid instead of blinking: check blinkLED() is being called and that delay values aren't 0.

Phase 3 — Authorized / Unauthorized Cards + OLED

Phase 3
phase3_auth_oled/phase3_auth_oled.ino

Goal

Turn a raw UID into a real access decision — the first "digital identity" logic in the system. Compare a scanned UID against two known UIDs, show ACCESS GRANTED / ACCESS DENIED on the OLED, and give synced sound + light feedback:

  • Authorized → 1 beep + 1 LED blink
  • Unauthorized/Unknown → 2 beeps + 2 LED blinks

Hardware

RC522 (Phase 1 wiring) + Buzzer module (VCC→3.3V, GND→GND, I/O→GPIO4) + OLED (SDA→GPIO21, SCL→GPIO22) + onboard LED (GPIO2, no extra wiring needed).

How to Get Your UIDs

Run Phase 1 or 2, scan each card, copy the printed UID (no spaces, uppercase) into AUTHORIZED_UID/UNAUTHORIZED_UID.

Full Code

cpp#include <SPI.h>
#include <MFRC522.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SS_PIN     5
#define RST_PIN    27
#define BUZZER_PIN 4
#define LED_PIN    2      // ESP32 onboard LED on most 30-pin boards

#define SCREEN_WIDTH   128
#define SCREEN_HEIGHT  64
#define SCREEN_ADDRESS 0x3C

MFRC522 rfid(SS_PIN, RST_PIN);
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

// ---- EDIT with your real UIDs ----
String AUTHORIZED_UID   = "E1A12707";
String UNAUTHORIZED_UID = "52B2535D";
// -----------------------------------

void setup() {
  Serial.begin(115200);
  while (!Serial);

  SPI.begin();
  rfid.PCD_Init();

  pinMode(LED_PIN, OUTPUT);
  digitalWrite(LED_PIN, LOW);

  Wire.begin(21, 22);
  if (!display.begin(SSD1306_SWITCHCAPVCC, SCREEN_ADDRESS)) {
    Serial.println("OLED not found - check wiring/address.");
  }

  showMessage("Phase 3 Ready", "Scan a card...");
  Serial.println("Phase 3: Authorized/Unauthorized + OLED + LED ready.");
}

void loop() {
  if (!rfid.PICC_IsNewCardPresent()) return;
  if (!rfid.PICC_ReadCardSerial())   return;

  String uid = getUIDString();
  Serial.print("Scanned UID: "); Serial.println(uid);

  if (uid == AUTHORIZED_UID) {
    Serial.println("ACCESS GRANTED");
    showMessage("ACCESS GRANTED", uid);
    feedback(1);   // 1 beep + 1 blink

  } else if (uid == UNAUTHORIZED_UID) {
    Serial.println("ACCESS DENIED");
    showMessage("ACCESS DENIED", uid);
    feedback(2);   // 2 beeps + 2 blinks

  } else {
    Serial.println("UNKNOWN CARD - ACCESS DENIED");
    showMessage("UNKNOWN CARD", "ACCESS DENIED");
    feedback(2);   // treated the same as denied
  }

  rfid.PICC_HaltA();
  rfid.PCD_StopCrypto1();

  delay(1500);
  showMessage("Phase 3 Ready", "Scan a card...");
}

String getUIDString() {
  String result = "";
  for (byte i = 0; i < rfid.uid.size; i++) {
    if (rfid.uid.uidByte[i] < 0x10) result += "0";
    result += String(rfid.uid.uidByte[i], HEX);
  }
  result.toUpperCase();
  return result;
}

void showMessage(String line1, String line2) {
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0, 10);
  display.println(line1);
  display.setCursor(0, 30);
  display.println(line2);
  display.display();
}

// Plays `count` beeps and blinks the LED `count` times, together, in sync.
// 1 = authorized feedback, 2 = denied/unknown feedback.
void feedback(int count) {
  for (int i = 0; i < count; i++) {
    tone(BUZZER_PIN, 1000);
    digitalWrite(LED_PIN, HIGH);
    delay(180);
    noTone(BUZZER_PIN);
    digitalWrite(LED_PIN, LOW);
    delay(150);
  }
}

Code Walkthrough

  • Buzzer uses tone()/noTone() instead of digitalWrite() HIGH/LOW — a buzzer module needs an oscillating signal to produce real sound (a static HIGH only makes a faint "tick" at the transition).
  • feedback(count): one function drives both the buzzer AND the LED together, count times — this guarantees the beep and blink are always in sync, no separate calls to keep aligned by hand. This exact function carries through Phases 3–5 unchanged.
  • AUTHORIZED calls feedback(1); both UNAUTHORIZED and UNKNOWN call feedback(2) — matching "sound once for right card, twice for wrong."
✅ Checkpoint

Scan the authorized card → "ACCESS GRANTED", one beep + one LED blink. Scan the unauthorized card → "ACCESS DENIED", two beeps + two LED blinks. Scan a third/unknown card → "UNKNOWN CARD", same two beep/blink pattern.

Common Errors
  • Beep/blink out of sync: shouldn't happen since both are driven by the same loop iteration — check nothing else is calling tone()/digitalWrite(LED_PIN) separately.
  • Buzzer silent: confirm you're using tone(), not digitalWrite().

Phase 4 — Clock In / Clock Out + Name + Duration + OLED

Phase 4
phase4_clockinout_oled/phase4_clockinout_oled.ino

Goal

Move past a binary granted/denied decision into the actual product: each registered card toggles between CLOCK IN and CLOCK OUT on successive scans. Shows the person's name and, on clock-out, how long they were clocked in — all on the OLED, with synced sound + light feedback:

  • Clock In → 1 beep + 1 LED blink
  • Clock Out → 2 beeps + 2 LED blinks
  • Not Registered → 3 beeps + 3 LED blinks

No Wi-Fi yet (that's Phase 5) — duration uses millis() (time since boot), a relative clock.

Hardware

RC522 + Buzzer (VCC→3.3V, GND→GND, I/O→GPIO4) + OLED (SDA→GPIO21, SCL→GPIO22) + onboard LED (GPIO2, no extra wiring).

Full Code

cpp#include <SPI.h>
#include <MFRC522.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SS_PIN     5
#define RST_PIN    27
#define BUZZER_PIN 4
#define LED_PIN    2      // ESP32 onboard LED on most 30-pin boards

#define SCREEN_WIDTH   128
#define SCREEN_HEIGHT  64
#define SCREEN_ADDRESS 0x3C

MFRC522 rfid(SS_PIN, RST_PIN);
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

// ---- Registered cards: EDIT with your real UIDs + names ----
// name can be "Name1,Name2" for a shared/team card
struct CardRecord {
  String uid;
  String name;
  bool   isClockedIn;
  unsigned long clockInTime;
};

const int NUM_CARDS = 2;
CardRecord cards[NUM_CARDS] = {
  { "E1A12707", "Student One",false, 0 },
  { "52B2535D", "Student Two,Student Three", false, 0 },
};
// NUM_CARDS must exactly match the number of entries above.

void setup() {
  Serial.begin(115200);
  while (!Serial);

  SPI.begin();
  rfid.PCD_Init();

  pinMode(LED_PIN, OUTPUT);
  digitalWrite(LED_PIN, LOW);

  Wire.begin(21, 22);

  }

  Serial.println("Phase 4: Clock In/Out + OLED + LED ready.");
}

void loop() {
  if (!rfid.PICC_IsNewCardPresent()) return;
  if (!rfid.PICC_ReadCardSerial())   return;

  String uid = getUIDString();
  handleScan(uid);

  rfid.PICC_HaltA();
  rfid.PCD_StopCrypto1();
}

String getUIDString() {
  String result = "";
  for (byte i = 0; i < rfid.uid.size; i++) {
    if (rfid.uid.uidByte[i] < 0x10) result += "0";
    result += String(rfid.uid.uidByte[i], HEX);
  }
  result.toUpperCase();
  return result;
}

int findCard(String uid) {
  for (int i = 0; i < NUM_CARDS; i++) {
    if (cards[i].uid == uid) return i;
  }
  return -1;
}

void handleScan(String uid) {
  int idx = findCard(uid);

  if (idx == -1) {
    Serial.print("UID: "); Serial.println(uid);
    Serial.println("NOT REGISTERED");
    showMessage("Not Registered", uid);
    feedback(3);
    delay(1500);
    showMessage("Phase 4 Ready", "Scan to clock in/out");
    return;
  }

  CardRecord &card = cards[idx];

  if (!card.isClockedIn) {
    // ---- CLOCK IN ----
    card.isClockedIn = true;
    card.clockInTime = millis();

    Serial.println("----- CLOCK IN -----");
    Serial.print("Name: "); Serial.println(card.name);

    showMessage(card.name, "CLOCKED IN");
    feedback(1);

  } else {
    // ---- CLOCK OUT ----
    unsigned long durationMs = millis() - card.clockInTime;
    card.isClockedIn = false;

    String duration = formatDuration(durationMs);

    Serial.println("----- CLOCK OUT -----");
    Serial.print("Name: "); Serial.println(card.name);
    Serial.print("Duration: "); Serial.println(duration);

    showMessage(card.name, "OUT - " + duration);
    feedback(2);
  }

  delay(1800);
  showMessage("Phase 4 Ready", "Scan to clock in/out");
}

String formatDuration(unsigned long ms) {
  unsigned long totalSeconds = ms / 1000;
  unsigned long minutes = totalSeconds / 60;
  unsigned long seconds = totalSeconds % 60;
  return String(minutes) + "m " + String(seconds) + "s";
}

void showMessage(String line1, String line2) {
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0, 10);
  display.println(line1);
  display.setCursor(0, 30);
  display.println(line2);
  display.display();
}

    noTone(BUZZER_PIN);

}

Code Walkthrough

  • CardRecord struct + cards[] array: this is the "digital identity database" — each known tag's UID, name, and live clock state. NUM_CARDS must exactly match the number of entries.
  • findCard(uid) looks up a scanned UID in the registry; returns -1 if not found — this replaces Phase 3's two hardcoded UID comparisons with a scalable lookup.
  • handleScan(uid) toggles isClockedIn for the matched card and computes duration via formatDuration() on clock-out.
  • feedback(count) is the exact same helper from Phase 3, just called with a new meaning: 1 = clock in, 2 = clock out, 3 = not registered.
✅ Checkpoint

Scan a known card once → "<Name> / CLOCKED IN", 1 beep. Scan it again → "<Name> / OUT - Xm Ys", 2 beeps. Scan an unregistered card → "Not Registered", 3 beeps.

Common Errors
  • Same as Phase 3: if buzzer is silent, confirm tone() is being used, not digitalWrite().
  • Same card toggles twice from one tap: PICC_HaltA()/PCD_StopCrypto1() (already present) usually prevents this; a brief extra delay after handling a scan is a simple additional safeguard if it still happens.

Phase 5 — Wi-Fi + Server + OLED

Phase 5
phase5_wifi_server_oled/phase5_wifi_server_oled.ino

Goal

Every LOGIN/LOGOUT event gets pushed to a server the moment it happens, instead of staying trapped on the board. This is a single-card, per-device clock-in/out client: connects to Wi-Fi, toggles clock in/out on tap, and POSTs the event as JSON. Same buzzer/LED feedback pattern as Phases 3–4:

  • Clock In → 1 beep + 1 blink
  • Clock Out → 2 beeps + 2 blinks
  • Wrong/unregistered card → 3 beeps + 3 blinks

Hardware / Pins

  • OLED: SDA→GPIO21, SCL→GPIO22, VCC→3.3V, GND→GND
  • Buzzer: I/O→GPIO4, VCC→3.3V, GND→GND
  • Onboard LED: GPIO2 (already on the board, no wiring needed)

Libraries Required

MFRC522, ArduinoJson, Adafruit GFX, Adafruit SSD1306

Full Code

cpp#include <SPI.h>
#include <MFRC522.h>
#include <WiFi.h>
#include <HTTPClient.h>
#include <ArduinoJson.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SS_PIN     5
#define RST_PIN    27
#define BUZZER_PIN 4
#define LED_PIN    2      // ESP32 onboard LED on most 30-pin boards

#define SCREEN_WIDTH   128
#define SCREEN_HEIGHT  64
#define SCREEN_ADDRESS 0x3C   // try 0x3D if the screen stays blank

MFRC522 rfid(SS_PIN, RST_PIN);
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

// ============ SAME FOR EVERYONE - set once, share with the class ============
const char* WIFI_SSID     = "wife_ssid";
const char* WIFI_PASSWORD = "type your password here";
const char* SERVER_URL    = "http://10.10.49.227:5000/events";  // instructor's laptop IP
// ==============================================================================

// ============ EDIT ME - each student fills in their OWN details ============
String MY_NAME     = "your name here";
String MY_CARD_UID = "card uid active on your card, e.g. 93A74C21";  // tap your card in Phase 1 to discover this
// ==============================================================================

bool isClockedIn = false;
unsigned long lastWifiCheck = 0;
const unsigned long WIFI_CHECK_INTERVAL = 5000;

void setup() {
  Serial.begin(115200);
  while (!Serial);

  SPI.begin();
  rfid.PCD_Init();

  pinMode(LED_PIN, OUTPUT);
  digitalWrite(LED_PIN, LOW);

  Wire.begin(21, 22);  // SDA, SCL
  if (!display.begin(SSD1306_SWITCHCAPVCC, SCREEN_ADDRESS)) {
    Serial.println("OLED not found - check wiring/address.");
  }
  showMessage("Starting...", "");

  connectToWiFi();

  Serial.println("Ready.");
  if (MY_CARD_UID == "UNKNOWN") {
    Serial.println("MY_CARD_UID not set yet - tap your card to discover it.");
    showMessage("Tap card to", "discover UID");
  } else {
    showIdleScreen();
  }
}

void loop() {
  String uid;
  if (readRFID(uid)) {

    if (MY_CARD_UID == "UNKNOWN") {
      Serial.print("Detected UID: "); Serial.println(uid);
      Serial.println("Copy this into MY_CARD_UID, then re-upload.");
      showMessage("UID found:", uid);
      feedback(3);
      delay(2000);
      showMessage("Tap card to", "discover UID");
      return;
    }

    if (uid != MY_CARD_UID) {
      Serial.println("This isn't the registered card for this device - ignoring.");
      showMessage("Wrong card!", "Not registered");
      feedback(3);
      delay(1500);
      showIdleScreen();
      return;
    }

    handleScan();
  }

  if (millis() - lastWifiCheck > WIFI_CHECK_INTERVAL) {
    lastWifiCheck = millis();
    if (WiFi.status() != WL_CONNECTED) {
      showMessage("WiFi lost...", "Reconnecting");
      connectToWiFi();
      showIdleScreen();
    }
  }
}

void connectToWiFi() {
  Serial.print("Connecting to Wi-Fi...");
  showMessage("Connecting to", "WiFi...");
  WiFi.mode(WIFI_STA);
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  unsigned long start = millis();
  while (WiFi.status() != WL_CONNECTED && millis() - start < 15000) {
    delay(300);
    Serial.print(".");
  }
  Serial.println();
  if (WiFi.status() == WL_CONNECTED) {
    Serial.print("Connected. IP: "); Serial.println(WiFi.localIP());
    showMessage("WiFi Connected", WiFi.localIP().toString());
    delay(1000);
  } else {
    Serial.println("Wi-Fi connect failed, will retry in background.");
    showMessage("WiFi Failed", "Retrying later");
    delay(1000);
  }
}

bool readRFID(String &uid) {
  if (!rfid.PICC_IsNewCardPresent()) return false;
  if (!rfid.PICC_ReadCardSerial())   return false;

  uid = "";
  for (byte i = 0; i < rfid.uid.size; i++) {
    if (rfid.uid.uidByte[i] < 0x10) uid += "0";
    uid += String(rfid.uid.uidByte[i], HEX);
  }
  uid.toUpperCase();

  rfid.PICC_HaltA();
  rfid.PCD_StopCrypto1();
  return true;
}

void handleScan() {
  String eventType = isClockedIn ? "CLOCK_OUT" : "CLOCK_IN";
  isClockedIn = !isClockedIn;

  Serial.print("Name: "); Serial.println(MY_NAME);
  Serial.print("Event: "); Serial.println(eventType);

  if (eventType == "CLOCK_IN") {
    feedback(1);
    showMessage(MY_NAME, "CLOCKED IN");
  } else {
    feedback(2);
    showMessage(MY_NAME, "CLOCKED OUT");
  }

  bool sent = sendEvent(eventType);
  delay(1200);
  showStatusResult(sent);
  delay(1000);
  showIdleScreen();
}

bool sendEvent(String eventType) {
  if (WiFi.status() != WL_CONNECTED) {
    Serial.println("No Wi-Fi - event NOT sent.");
    return false;
  }

  StaticJsonDocument<256> doc;
  doc["uid"]        = MY_CARD_UID;
  doc["name"]       = MY_NAME;
  doc["event_type"] = eventType;

  String payload;
  serializeJson(doc, payload);

  HTTPClient http;
  http.begin(SERVER_URL);
  http.addHeader("Content-Type", "application/json");
  int httpCode = http.POST(payload);

  bool success = (httpCode > 0 && httpCode < 300);

  if (httpCode > 0) {
    Serial.print("Server responded: "); Serial.println(httpCode);
  } else {
    Serial.print("POST failed: "); Serial.println(http.errorToString(httpCode));
  }
  http.end();
  return success;
}

Code Walkthrough

  • connectToWiFi(): connects with a 15-second timeout, shows connection status on OLED, and is retried automatically in loop() every WIFI_CHECK_INTERVAL (5s) if the connection drops.
  • readRFID(uid): wraps Phase 1–2's present/read/halt sequence into one boolean helper returning the UID string.
  • handleScan(): toggles isClockedIn, gives feedback + OLED message, then calls sendEvent() to POST to the server and shows whether the send succeeded.
  • sendEvent(eventType): builds a small JSON payload (uid, name, event_type) with ArduinoJson, POSTs it via HTTPClient, and returns success/failure based on the HTTP status code — this is exactly the shape server.py's /events route expects (see Appendix C).

Common Errors
  • Wi-Fi connect failed: sketch continues and retries connecting in the background every 5s; events won't send until reconnected.
  • "Send FAILED" on OLED: check SERVER_URL matches the instructor's current laptop IP and that server.py is running and reachable on the same Wi-Fi.
  • UID not recognized as yours: confirm MY_CARD_UID was copied exactly (uppercase, no spaces) from discovery mode.
